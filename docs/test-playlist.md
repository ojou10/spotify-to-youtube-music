# Controlled test playlist

Before attempting the approximately 2,500-track playlist, use a small public Spotify playlist owned by the connected account containing:

- one exact studio track;
- one remaster and one live version;
- one cover or karaoke result;
- one duplicate position;
- one unavailable or unsupported item;
- one intentionally unmatched item.

Verify the review queue, explicit decisions, exact destination order, duplicate preservation, append-only behavior, interruption recovery, destination link, and CSV/JSON reports. Keep the playlist small and disposable. This is a manual acceptance gate; live contract tests are read-only.
